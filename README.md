# 📱 Smartphone Price Drop Prediction

A Machine Learning project that predicts the expected price drop of smartphones based on their features.

## 🚀 Project Overview

This project uses Machine Learning to predict the price drop of smartphones by analyzing different features such as brand, RAM, storage, original price and current price.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Joblib

## 📊 Machine Learning Model

Decision Tree Regressor is used to predict the smartphone price drop.

## 🔄 Project Workflow

1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis
5. Feature Engineering
6. Model Training
7. Model Evaluation
8. Price Drop Prediction
9. Streamlit Deployment

## 📂 Project Files

- `app.py` – Streamlit application
- `dia.py` – Data analysis / preprocessing
- `model.pkl` – Trained Machine Learning model
- `requirements.txt` – Required Python libraries
- `smartphone_price_drop_dataset (1).xlsx` – Dataset
